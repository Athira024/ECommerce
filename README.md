# BookWorm – Online Bookstore

BookWorm is an e-commerce web application developed for buying books online. It provides a user-friendly interface that allows users to browse and explore books.

The project was developed using ASP.NET, C#, and Microsoft SQL Server.

## Features
- User Authentication: User registration, login and logout functionality.
- Product Categories: Browse books based on categories or genres.
- Product Listing: Display available books with details such as title, price and description.
- Shopping Cart: Add books to the cart, update quantities and remove items.
- Cart Management: View selected books and calculate the total price.
- Book Details: View individual book information before purchasing.
- Order Management: Place orders and manage the purchasing process.
- Database Integration: Store and manage product, user and order information using SQL Server.
- User-friendly interface for exploring books

## Technologies Used

- **Backend:** ASP.NET, C#
- **Frontend:** HTML, CSS, JavaScript
- **Database:** Microsoft SQL Server

## Tools

- Visual Studio
- SQL Server Management Studio
- Git and GitHub

## Project Purpose

This project was developed to gain hands-on experience in ASP.NET web development, C#, database connectivity, and e-commerce application development.
